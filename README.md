# Hoodverse - Premium Unisex Hoodies E-Commerce Website

A modern, fully responsive e-commerce website for selling premium unisex hoodies. Built with HTML, CSS, JavaScript, and Bootstrap, featuring a sleek dark theme with gradient effects and smooth animations.

## 🌟 Features

### Core Functionality
- **Product Catalog**: Browse through a collection of premium unisex hoodies
- **Shopping Cart**: Add items to cart with color and size selection
- **User Authentication**: Login/Register system with localStorage
- **Order Management**: Place orders and track order status
- **Search Functionality**: Search products by name or description
- **Responsive Design**: Fully responsive across all devices (mobile, tablet, desktop)

### User Features
- **Product Details**: View detailed product information with images
- **Color & Size Selection**: Choose from multiple color and size options
- **Cart Management**: Add, remove, and update cart items
- **Checkout Process**: Complete checkout with delivery information
- **Payment Options**: Support for GCash and Cash on Delivery (COD)
- **Order Tracking**: Track order status in real-time
- **Contact Form**: Send messages through the contact form

### Design Features
- **Modern UI/UX**: Dark theme with gradient backgrounds and glassmorphism effects
- **Smooth Animations**: Hover effects and transitions throughout
- **Beautiful Typography**: Google Fonts (Montserrat & Poppins)
- **Icon Integration**: Font Awesome icons for enhanced visual appeal
- **Philippines Support**: Localized for Philippine market with GCash payment

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional, for best experience)

### Installation

1. **Clone or download the repository**
   ```bash
   git clone <repository-url>
   cd Hoodie
   ```

2. **Open the website**
   - Simply open `index.html` in your web browser, or
   - Use a local server for better experience:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js (http-server)
     npx http-server
     
     # Using PHP
     php -S localhost:8000
     ```

3. **Access the website**
   - Open your browser and navigate to `http://localhost:8000`
   - Or directly open `index.html` in your browser

The application uses **localStorage** to store:
- User accounts
- Shopping cart items
- Order history
- Contact messages

**Note**: Data is stored locally in the browser and will be cleared if:
- Browser cache is cleared
- User switches browsers/devices
- Incognito/private mode is used
